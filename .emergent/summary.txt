<product_requirements>
The goal is to build a comprehensive ride-hailing ecosystem inspired by Uber, specifically cloning the modern Uber India mobile application UI and its diverse services.

**Core Application (Passenger App):**
- A mobile-first React application replicating the provided Uber India UI.
- Must include multiple service categories: Trip (standard ride), Bike, Shuttle (Indian-style fixed routes), Rentals, Send Items (parcel delivery), Intercity, Toto (auto-rickshaw), and Store pick-up.
- Features a full booking flow: location search (powered by OpenStreetMap), ride/service selection, dynamic pricing, and a map view.
- Supports both on-demand shared rides (Uber Share) and scheduled, fixed-route bus services (Shuttle).

**Supporting Ecosystem:**
- **Driver App:** Allows drivers to accept rides, view routes, and manage their status.
- **Fleet App:** For fleet managers to oversee vehicles and drivers.
- **Corporate Admin App:** To manage corporate shuttle services for staff.
- **Master Admin App:** An overarching control panel for platform administrators.

**Technical & Security Requirements:**
- A robust Role-Based Access Control (RBAC) system must be implemented across the entire ecosystem, enforcing the principle of least privilege for roles like Parent/Passenger, Driver, and various Admins.
- The backend, built with FastAPI and MongoDB, must securely handle all data, API requests, and business logic for all applications.
- Safety features like an SOS button and verification via QR codes are required.
</product_requirements>
